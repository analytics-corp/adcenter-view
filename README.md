# 광고 성과 조회 화면 기획 목업

가상 데이터로 만든 화면 기획용 목업입니다. 실제 실적이 아니며, 화면 구조와 지표 정의를 검토하기 위한 용도입니다.

- 파일 하나(index.html)로 동작하며 외부 라이브러리와 서버가 없습니다.
- 주소창의 주소(# 뒤 포함)를 복사해 공유하면 지금 보는 화면과 필터가 그대로 열립니다.
- 화면 오른쪽 위 '광고 구좌 안내'는 구좌 위치를 보여주는 안내 페이지(hmall-ad-map.vercel.app)를 새 창으로 엽니다. '구좌별 현황' 탭의 화면 예시는 그 페이지의 앱 화면 캡처를 잘라 파일 안에 넣은 것입니다.
- 이 저장소에는 실제 데이터가 없습니다.
- 이 저장소의 파일은 비공개 작업 저장소에서 GitHub Actions로 자동 복사됩니다. 수정은 작업 저장소에서 하며, 여기서 직접 고친 내용은 다음 복사 때 사라집니다.
