# Hmall 비즈니스 인사이트 (partners_center — 협력사 파트너 시스템 화면 목업)

협력사(판매자)용 파트너 시스템 화면 목업입니다. 수치는 실제 실적·계약이 아니며, 개발팀과 화면 구성·지표 정의를 논의하기 위한 참조 구현입니다.

- 파일 하나(index.html)로 동작하며 외부 라이브러리와 서버가 없습니다. 홈 대시보드, 비즈니스 인사이트(데일리 요약·판매 트렌드·유입 트렌드·비교 분석·AI 데이터 분석·가망 고객), 전자계약 4화면(전자계약관리·프로모션 개별계약서·광고비·광고구좌), 통계 5화면을 담았습니다.
- 주소창의 주소(# 뒤 포함)를 복사해 공유하면 지금 보는 화면·기간·필터가 그대로 열립니다.
- [엑셀 다운로드]는 브라우저가 .xlsx 파일을 만들 뿐 서버 요청이 없습니다. 서명·반려·승인·계약서 등록은 화면 안에서만 반영됩니다.
- 지표 정의와 집계 기준은 왼쪽 메뉴 맨 아래 '지표 기준 안내'에 있습니다.
- 이 저장소에는 실제 데이터가 없습니다.
- 이 폴더의 파일은 비공개 작업 저장소에서 GitHub Actions로 자동 복사됩니다. 수정은 작업 저장소에서 하며, 여기서 직접 고친 내용은 다음 복사 때 사라집니다.
