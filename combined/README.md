# 통합 광고센터 예시 (adcenter_combined — 광고센터 + 판매자 인사이트 참조 목업)

가상 데이터로 만든 광고주용 광고센터 + 판매자 인사이트 화면 예시입니다. 실제 실적이 아니며, 개발팀과 화면 구성·지표 정의를 논의하기 위한 참조 구현입니다.

- 파일 하나(index.html)로 동작하며 외부 라이브러리와 서버가 없습니다. 같은 사이트의 상위 경로에 있는 광고 성과 조회 화면 목업과 같은 가상 데이터 생성부를 씁니다.
- 주소창의 주소(# 뒤 포함)를 복사해 공유하면 지금 보는 화면·기간·필터가 그대로 열립니다.
- 표의 'CSV 내려받기'와 오른쪽 위 'HTML 저장'은 브라우저가 파일을 만들 뿐 서버 요청이 없습니다. 오른쪽 위 '광고 구좌 안내'는 구좌 위치 안내 페이지(hmall-ad-map.vercel.app)를 새 창으로 엽니다.
- 신규 구매 고객·참여수·정산 금액·판매자 인사이트(방문·조회·유입경로) 등 예시 전용 지표는 정의 확정 전의 가상값입니다('기준 안내' 메뉴 참고). 규칙·예산·보고서 요청은 화면 안에서만 반영됩니다.
- 이 저장소에는 실제 데이터가 없습니다.
- 이 폴더의 파일은 비공개 작업 저장소에서 GitHub Actions로 자동 복사됩니다. 수정은 작업 저장소에서 하며, 여기서 직접 고친 내용은 다음 복사 때 사라집니다.
