지표 정의와 집계 기준

확정 = 팀 결정 완료 · 계획 = 실데이터 연결 시 적용 · 확인 필요 = 미검증
전체 매출 확정
광고 배너로 노출된 상품의 해당 일자 전체 매출입니다. 해당 배너를 거치지 않은 구매도 포함하며 접수일자 기준으로 집계합니다.
직접 매출 확정
해당 배너(전시영역코드)를 통해 발생한 거래만 집계한 매출.
직접 기여율
직접 매출 ÷ 전체 매출.
집행 광고비 확정
구좌 단가 × 노출 일수. 단가는 26.08 광고상품 단가표의 구좌별 개별 단가이며 상단·중단·하단 구간을 반영합니다. 매출이 없는 노출일도 과금됩니다. 단가표에 없는 구좌는 광고비 산정에서 제외합니다.
패키지·협의가 확인 필요
패키지(파워·포커스·웰컴) 등으로 판매된 건의 실제 청구액은 개별 단가 합산과 다를 수 있습니다. 광고편성 계약 자료와 대조하기 전까지 집행 광고비와 ROAS는 개별 단가 기준 참고값입니다.
ROAS 확정
전체 매출 ÷ 집행 광고비. 백분율로 표시하며 직접 매출 기준 ROAS는 표시하지 않습니다. 전년 대비 증감은 상대 증감률(▲%)과 퍼센트포인트(+%p)를 함께 보이고, 구좌 표는 퍼센트포인트만 보입니다.
클릭수 · 노출수 계획
GA4 구좌별 실측값으로 교체 예정이며, 목업의 값은 가상입니다.
전년 동월 대비 확정
같은 달(분기 선택 시 전년 동분기)의 전년 값과 비교한 증감입니다. 신장률 = (올해 − 전년) ÷ 전년.
합계 보는 법 계획
같은 상품이 여러 구좌에 동시에 노출되면 구좌별 전체 매출은 각각 독립적으로 집계되므로, 구좌별 값을 더한 금액과 상단 합계는 다를 수 있습니다. 상단 합계는 매장ID·판매상품코드·접수일자 기준으로 중복을 제거한 값으로 표시할 예정입니다. 목업은 중복이 없는 가상 데이터를 그대로 합산합니다.
날짜 기준 확정
추출은 접수일자, 배너 귀속은 주문일자 ≥ 전시시작일 하한 가드를 적용합니다. 취소·반품은 접수된 날에 반영합니다. 전시 시작 이전에 주문된 건의 취소·반품은 전체 매출에서 제외하고, 전시 시작 이후 주문의 취소·반품은 정상 판매 사이클로 보아 반영하므로 반품이 많은 배너는 전체 매출이 낮거나 일부 마이너스로 보일 수 있습니다.

링크 공유와 화면 갱신

링크에 담기는 내용
보고 있는 화면, 기간, 팀·MD·브랜드·광고 구좌 선택, 캠페인 검색어와 정렬, 펼쳐 둔 MD 행이 주소 뒤쪽(#)에 기록됩니다. 상단의 '링크 복사'를 누르면 이 상태 그대로 열리는 링크가 복사됩니다.
수정 반영 방식 계획
링크는 웹 서버의 주소입니다. 같은 위치의 화면 파일이나 데이터 파일을 교체하면 링크는 그대로이고, 서버가 열 때마다 최신 파일을 확인하도록 설정되어 있으면 새로고침만으로 새 내용이 보입니다. 이 목업을 내 PC에서 파일로 열었을 때는 내 PC 경로가 복사되므로, 사내 웹 주소에 게시한 뒤에 팀원에게 공유할 수 있습니다.
